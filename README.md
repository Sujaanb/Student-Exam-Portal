# Student Examination Portal

A Python-based system for managing students, courses, batches, and departments with automated report generation and performance analytics.

## Features
- Student management (create, update, delete)
- Course and batch organization
- Automated grade calculation and report cards
- Performance visualization (pie charts, scatter plots)
- Search functionality across all entities
- Data validation and error handling

## Installation
```bash
git clone https://github.com/Sujaanb/Student-Exam-Portal.git
cd Student-Exam-Portal
pip install -r requirements.txt
python py_project/main.py
```
